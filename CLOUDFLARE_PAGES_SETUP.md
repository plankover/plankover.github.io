# Публикация План «Ковер» на Cloudflare Pages

Цель: публичная карта на `https://plankover.ru`, GitHub остается репозиторием исходников и конвейера сбора данных.

## Подготовлено в репозитории

- Сайт статический: `index.html` находится в корне.
- Каталоги `data/` и ресурс аватара находятся рядом с сайтом.
- `_headers` отключает длительное кеширование `data/*.json` и просит браузер перепроверять HTML, чтобы карта быстрее получала актуальные данные.
- Файл не меняет работу сборщика данных и не переключает публичный домен.

## Создание Pages проекта

1. Войдите в Cloudflare Dashboard: https://dash.cloudflare.com/ → Workers & Pages → Create → Pages → Connect to Git.
2. Подключите GitHub и выберите `plankover/plankover.github.io`, production branch `main`.
3. Для статического сайта без сборки задайте:
   - Framework preset: None
   - Build command: оставить пустым
   - Build output directory: `.` (корень репозитория)
   - Root directory: оставить пустым/корень
4. Запустите Deploy. Откройте адрес `https://<имя-проекта>.pages.dev` и проверьте карту, обновление, поиск, фильтры, попапы и экспорт изображения.

Если интерфейс Pages не принимает `.` как output directory или сборка падает, остановитесь и проверьте Build log: не переключайте домен. Альтернативно можно опубликовать заранее подготовленную папку через Wrangler/direct upload, но тогда отдельно настраивается повторная публикация.

## Домен plankover.ru

Для корневого домена Cloudflare Pages требует, чтобы зона домена была добавлена в тот же Cloudflare account, где Pages-проект, и NS домена указывали на Cloudflare.

1. Сначала зарегистрируйте `plankover.ru` у регистратора на данные владельца. До этого шага домен не считается принадлежащим проекту.
2. В Cloudflare добавьте домен как сайт/zone и получите выданную пару nameserver.
3. У регистратора замените NS на точные значения, показанные Cloudflare. Сохраните прежние DNS записи и почтовые настройки; при необходимости перенесите их в зону Cloudflare перед переключением NS.
4. В Pages → проект → Custom domains → Set up a domain добавьте `plankover.ru` и следуйте проверке.
5. После активации проверьте HTTPS и сайт на нескольких сетях/устройствах.
6. Не добавляйте `www` пока отдельно не решим, нужен ли он; основной адрес — без `www`.

## Переключение

До проверки нового адреса текущий GitHub Pages сайт остается доступным. После проверки Cloudflare и домена обновите ссылку в Telegram/описаниях. Репозиторий, Actions и сборщик данных остаются на GitHub.

## Проверка после каждого обновления

- Главная загружается по HTTPS.
- `data/data.json` отдается без длительного кеша.
- Кнопка обновления работает.
- Маркеры, статусы, фильтры и карточки совпадают с текущими данными.
- Экспорт снимка работает.
- Проверьте журналы deployment и дату последней успешной публикации.
